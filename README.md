# PRODIGY_DS_01

## Task
Create a bar chart or histogram to visualize the distribution of a categorical or continuous variable.

## Objective
To visualize population distribution using Python.

## Dataset
World Development Indicators (Population Dataset)

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Visualizations
- Histogram of Population Distribution
- Bar Chart of Top 10 Most Populous Countries

## Insights
- Most countries have relatively small populations.
- India has the highest population.
- China is the second most populous country.
- Population distribution is positively skewed.

## Conclusion
The charts help understand global population distribution and compare the world's most populous countries.
